# DAYMARK — redesign v2

Что изменено:
- полностью пересобрана главная страница вокруг бренда, продукта и двух сценариев B2C/B2B;
- переработана продуктовая страница: категории, поиск, единые карточки и модальное окно с характеристиками;
- добавлены отдельные более содержательные страницы «О бренде», «Партнёрам», «Где купить», «Контакты»;
- добавлена мобильная нижняя навигация;
- сохранены исходные изображения и фактические характеристики, которые были в исходниках;
- неподтверждённые сведения намеренно не добавлялись;
- добавлена базовая доступность: keyboard-open для карточек, aria-label, focusable элементы;
- добавлена единая дизайн-система: navy / yellow / cream, крупная типографика, большие продуктовые композиции;
- добавлен поиск по товарам и переключение категорий по URL-хэшу;
- форма контактов сохранена через FormSubmit, но перед production-запуском её лучше перевести на собственный backend/CRM и добавить юридически корректное согласие/политику обработки данных.

Важно перед публикацией:
1. заменить email на корпоративный, если он уже есть;
2. добавить реальные торговые сети/маркетплейсы на странице «Где купить»;
3. добавить юридические реквизиты и политику конфиденциальности;
4. при наличии — добавить PDF-каталог, сертификаты/декларации и документы для B2B;
5. проверить актуальность состава, БЖУ и маркировки по физической упаковке.
